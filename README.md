एक बार की बात है- हरे-भरे जंगल में एक सोता, कबूतर और चूहा अच्छे दोस्त रहते थे।

एक दिन तीनों को पेड़ के नीचे एक जाल दिखा। कन्नूर बोता, "अरे, ये तो खतरनाक लग रहा है।" लेकिन तोता उत्सुक था - वी पास चला गया और जाल में फँस गया।

कबूतर घबराया, पर चूहे ने तुरंत अपनी तेज़ दाँतों से जाल काट दिया। तोता आज़ाद हो गया। तोता बोला, "अगर दोस्ती सच्ची हो, तो हर मुसीबत आसान है।"

तीरों हँसते हुए बोले - "हम तीनों साथ हैं, तो कोई डर नहीं।"
